# GEO AI Visibility — Codex Skill

Reusable Codex skill for auditing and improving websites for AI answer engines, SEO, and local visibility.

## Install for one repository
Copy the `geo-ai-visibility` folder to `<your-repository>/.codex/skills/geo-ai-visibility/`.

## Install globally
Copy the `geo-ai-visibility` folder to `~/.codex/skills/geo-ai-visibility/`.

Restart/reopen Codex if it does not discover the skill immediately.

## Invoke
`$geo-ai-visibility Проведи GEO-аудит этого проекта и подготовь приоритетный план. Ничего не меняй без согласования.`

To implement: `$geo-ai-visibility Проведи аудит и внедри безопасные технические GEO-улучшения. Проверь сборку и покажи diff.`

The skill is instructions, not an automatic crawler, analytics integration or a promise of AI citations.
